06 / XENITH ARCHIVE

EVERY MACHINE HAS A STORY.

XENITH // ARCHIVE 001

THE BEGINNING

Antes de existir uma garagem cheia de máquinas, antes dos nomes Spirit, Black Opal, Valkyrie ou Delux, existia apenas uma ideia.

Criar algo que não fosse apenas mais um carro.

A XENITH nasceu dessa ideia.

Cada projeto passou a carregar uma identidade própria. Alguns nasceram para velocidade. Outros para estilo. Outros simplesmente porque precisavam existir.

O objetivo nunca foi construir o maior número de carros.

Era construir carros que fossem lembrados.

THIS IS XENITH.

07 / ABOUT

WHAT IS XENITH?

XENITH é um projeto automotivo fictício criado para desenvolver máquinas únicas dentro do universo de FR Legends.

Cada carro possui seu próprio nome, identidade visual, categoria e história.

A XENITH não é apenas uma coleção de carros.

É uma coleção de histórias sobre quatro rodas.
